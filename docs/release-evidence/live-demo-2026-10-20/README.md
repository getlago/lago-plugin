# Live self-hosted demo, 2026-10-20

`skills/implementation/scripts/live_demo.py` ran `up`, `seed`, and `finalize` at clean commit `96c9d4c`. The script hash in `run-metadata.json` matches the committed file. Every phase was approved separately.

- **Target:** a new Compose project, `lago-plugin-demo-clean1`, created by the script with `getlago/lago:v1.55.0`, pinned by digest and bound to `127.0.0.1` only. `validate_demo_target.py` passed, and the URL traced to the project's published container port.
- **Isolation before seeding:**
  - no webhook endpoints;
  - no organization webhook URLs;
  - no SMTP;
  - PDF generation disabled;
  - Postgres event store.
- **Data:** synthetic and prefixed with `lago_plugin_demo_`. No Lago Cloud or remote service was contacted.

| Check | Result |
| --- | --- |
| Usage before invoicing | 1,017 cents: $9.80 of prior usage plus the $0.37 job |
| Replay of one event | HTTP 422 `value_already_exist`; usage amount and units unchanged |
| Subscription invoice, in advance | $99.00, money test PASS |

## Files

- `lago-subscription_invoice.json` and `lago-usage_invoice.json`: the finalized Lago invoice payloads.
- `expected-*.json`: independent expectations.
- `actual-*.json`: generated by `extract_actual.py`, hash-linked to the payloads.
- `lago-current-usage.json` and `replay.json`: the usage and replay observations.
- `run-metadata.json`: image, isolation, objects, results, source commit, and script hash.

Reproduce the money tests:

```bash
D=docs/release-evidence/live-demo-2026-10-20
python3 skills/implementation/scripts/money_test.py $D/expected-subscription_invoice.json $D/actual-subscription_invoice.json --actual-source $D/lago-subscription_invoice.json
python3 skills/implementation/scripts/money_test.py $D/expected-usage_invoice.json $D/actual-usage_invoice.json --actual-source $D/lago-usage_invoice.json
```

This proves one synthetic period on a local instance. It does not prove production readiness, wallet renewal, or behavior on Lago Cloud.
