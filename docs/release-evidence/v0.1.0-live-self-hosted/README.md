# v0.1.0 live self-hosted money test

Run date: 2026-08-28

Result: **PASS**

The release money test ran against an isolated local Lago `v1.52.1` instance using the official `getlago/lago:v1.52.1` image. The container used Compose project and container name `lago-plugin-demo-v1521`, volume `lago-plugin-demo-v1521_data`, UI `127.0.0.1:18080`, and API `127.0.0.1:13000`. The recorded image digest is `sha256:e0fa3a9bfdfeea607ac6fb8a24c010188451baf2358df351d18116a773c0a472`.

No Lago Cloud or company environment was contacted. Payment collection, external tax, email delivery, PDF generation, and external webhooks were disabled or unused. Every customer, subscription, metric, plan, and event identifier is synthetic.

The passing batch used new transaction IDs and Lago-assigned receipt timestamps, placing all four events unambiguously inside the active period. The excluded batch had zero billing impact.
